# PathMind — Learn Backwards. Build Forwards. (Phase 1–2 prototype)
Requires Node 20+. In IntelliJ IDEA open this folder, then in the Terminal tab:
```
npm install
npm run dev     # http://localhost:5173
npm test        # graph engine tests
npm run build
```
Progress is stored in browser localStorage. Backend, database, lessons and AI come in later phases.
